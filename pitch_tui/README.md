# Gatherly pitch TUI

Standalone terminal presentation for a vertical demo recording.

```bash
python3 pitch_tui/gatherly_pitch.py
```

Controls: `←` / `→` or `Space` to navigate, `1`–`9` to jump to a scene, `q` to quit.

Use a tall terminal window: around 64 columns and at least 28 rows. The application
uses the alternate terminal screen, so it does not leave presentation frames in shell
history.
