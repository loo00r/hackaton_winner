# Gatherly × Silpo MCP

**Gatherly** — Telegram-агент для організації групових подій у Сільпо. Він
перетворює повідомлення на кшталт «футбол о 20:00, нас п’ятеро, один веган,
бюджет 4 000 грн» на реальний, перевірений кошик.

## Що вміє

- Витягує з живого чату подію, час, кількість гостей, бюджет і обмеження.
- Сам отримує збережену адресу, доступний тип доставки, магазин і часовий слот.
- Шукає реальні товари через Silpo MCP українськими запитами; не вигадує ціни,
  наявність, слоти або checkout-посилання.
- Очищає застарілий кошик на старті нового event flow і збирає новий у
  щойно знайденому delivery context.
- Враховує веганські опції, алергії, дітей та алкогольні вподобання.
- Контролює бюджет, залишки, крок кількості та blocking validations кошика.
- Після кожної зміни перечитує кошик; перед фіналом перевіряє склад і
  поживність товарів, якщо MCP надав ці дані.
- Якщо користувач мовчить, запускає `SILENCE FOLLOW-UP`: шукає безпечний
  наступний варіант через MCP замість повторення питання.
- Показує Telegram `typing…` під час роботи та надсилає Telegram-friendly
  plain text без зламаного Markdown.
- Повторює OpenAI-запит після тимчасового `429 rate limit` до трьох разів.

## Agent flow

```text
Telegram message
  → agent_loop
  → LLM decides the next action
  → Silpo MCP tool call(s)
  → cart re-read and validation
  → concise Telegram response + checkout links
```

Підключені MCP-можливості: поточний кошик, очищення та оновлення кошика,
збережені адреси, типи доставки, магазини, часові слоти, пошук товарів,
деталі товарів, акції, обране та харчові обмеження.

## Запуск

Потрібні Python 3.14+, Telegram bot token, OpenAI API key і Silpo MCP token.
Створи `.env` у корені проєкту:

```env
BOT_TOKEN=...
OPENAI_API_KEY=...
SILPO_MCP_TOKEN=...
```

Поточна модель задається у `src/llm/client.py` (`gpt-4.1-mini`).

```bash
source .venv/bin/activate
python -m src.bot.bot
```

Після старту бот завантажує дозволені MCP tools, підключається до Silpo MCP і
починає polling Telegram. У терміналі видно короткі логи на кшталт
`MCP → silpo_find_products_batch` і `MCP ← ...`.
